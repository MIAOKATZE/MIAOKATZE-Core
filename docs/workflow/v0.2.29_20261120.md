# Core 0.2.29：基于 v0.2.25 的 Tooltip 修补

仅从 `v0.2.25`（`d411546eac7c0ea90c6eba00cdc8ca9173b708b1`）带入 Tooltip 主动固定修补及其对应测试，不纳入 0.2.26 的预览变更或 Lite。未固定的提示窗仍按 Chromatic 正常悬停显示，不再因指针移向旧窗或间隙而延续绘制；原有可改绑的主动固定（含玩家绑定的鼠标键）、已固定的父子窗与相应交互不变。见[原生 Tooltip 组件](../sum/native-tooltip.md)。

版本化前的这条源码线已通过独立 `TooltipPinStateContracts`，以及 `build -x spotlessJavaCheck --offline --no-configuration-cache --max-workers=1`（73 个执行、1 个缓存；`runNativePageContracts` 和 `runTooltipPinContracts` 均通过）。单独的 Spotless 检查仅报 v0.2.25 已有的六个未修改文件，未把整仓格式检查报为通过。上述是源码候选检查，不是最终 Tag 工件、真实客户端输入／绘制或发行状态的回执。
