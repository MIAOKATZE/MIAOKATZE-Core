## PackedVertexStream 同版本 API 增量（Core v0.2.6）

Core v0.2.6 增加有界 PackedVertexStream；本次是同版本增量，不更改既有公开 ScreenLineStream 方法签名。布局固定为 TEXTURED_QUADS、COLOR_QUADS、COLOR_TRIANGLE_STRIP；最多 16,368 顶点，惰性复用 staging 上限 392,832 B。double 世界坐标先加 Tessellator offset 后转 float，RGBA 量化与 vanilla setColorRGBA_F 相同。实现复用 Angelica 公共 TessellatorStreamingDrawer.drawPacked 路径和其缓冲，不自建 VBO。

begin 拒绝时调用方保留原完整 pass；成功后不能对同一 pass 重试。调用方在完整 primitive/source 边界主动 flush；内部失败后 end 只恢复状态、不重交。业务异常不保证 staging 回滚。owner/render-thread 与 GL context 生命周期约束、状态恢复范围见 docs/packed-vertex-stream.md。

旧版 Core 0.2.6 若未包含新类，GTSWN 运行时兼容探测会安静回退到原 renderer。GTMB 现有 Core 0.2.5 方法调用不变、无需升级；其他 Mod 不需跟进新类。
