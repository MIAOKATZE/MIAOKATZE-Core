# MIAOKATZE Core

Shared rendering primitives, passive TestKit utilities and extension contracts for the MIAOKATZE Minecraft 1.7.10 / GTNH mod family.

Consumer mods retain gameplay, dimensions, permissions and saved data. Java 8 bytecode; development baseline Forge 10.13.4.1614 and ModularUI2 2.3.92.

Initial implementation and compatibility documentation accompany version 0.1.1. Licensed under AGPL-3.0; extracted implementation provenance is recorded in NOTICE.md.
