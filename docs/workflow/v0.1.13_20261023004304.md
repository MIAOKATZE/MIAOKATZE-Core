# Core v0.1.13 KEEP GUI 世界输入分离

记录创建：2026-10-23 00:43:04 +08:00
记录更新：2026-10-23
目标版本：v0.1.13

## 兼容背景

GTSWN 工程相机使用 Core GuiPolicy.KEEP 时，需要继续显示工程背景，同时避免仅凭背景渲染状态开放世界输入。真实 GUI、Minecraft 焦点、DisplayActive 与 Core frame 分别决定可见内容和世界交互。

## 行为合同

GuiPolicy.KEEP 在真实 GUI 打开时保留工程背景，但不允许世界输入。只有无 GUI、游戏获得焦点且 DisplayActive 为 true 时，才允许 world input。真实失焦会清除 Core frame 与 pointer capture。

公开 API 签名不变，GuiPolicy.SUSPEND 与 RELEASE 语义不变；本轮没有改变其他 camera policy 的外部合同。

正交渲染期间跳过云几何绘制，避免高空虚拟镜头与地面锚点之间的云层遮住工厂；不修改用户云设置，普通视角照常绘云。几何合同覆盖四朝向下云面与地面的相交顺序。

## 构建合同

Core v0.1.13 首次完整 build 用时 13 秒通过。11 组 JavaExec 合同均实际执行，包括 CameraLease 与 CameraActivity 合同。Gradle JUnit test task 未发现测试，不提供 JUnit 测试数量。

真实客户端/输入部分证据和后续后台 MUI、自然 GL 采证范围统一留在 GTSWN 的 plan/implementation/v2.0.7/client/ 与 workflow 记录中。Core JavaExec 合同不代表 OS 原生键鼠通过；后台 MUI / GL 采证也不表述为 OS 原生输入验收。
