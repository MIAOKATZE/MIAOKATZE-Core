## 兼容问题

GTSWN 工程相机使用既有 GuiPolicy.KEEP 时，工程背景需要继续可见，但真实 GUI 与游戏世界输入的可交互状态必须分开判断。不能仅由渲染背景可见推断世界输入可用，也不能通过伪造焦点补齐状态。

## 本轮修复

Core 将渲染可见与 world interactive 状态分离：

- 真实 GUI 打开时继续显示工程背景，但不向世界分发输入。
- 只有没有 GUI、游戏获得焦点且 DisplayActive 为 true 时，世界输入才可用。
- 真实失焦会清除当前 Core frame 与 capture，防止旧输入状态跨失焦保留。

既有公开 API 签名不变；GuiPolicy.SUSPEND 与 RELEASE 语义不变。该修复面向 GTSWN v2.0.7 的真实窗口输入验证，不改变同代其他 camera policy 的公开合同。
