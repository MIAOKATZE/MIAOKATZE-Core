# Core issue #27（2026-11-07）

[问题报告](https://github.com/MIAOKATZE/MIAOKATZE-Core/issues/27)涉及 SDL GPU/Vulkan 渲染后端下的高度切片。Core 0.2.6 同版本修复按 `BackendManager.RENDER_BACKEND.isSDLGPU` 跳过 SliceShaders 的统一源码注入，并报告高度切片暂不可用；SDL 正常渲染保留。OpenGL 与 Iris 原有处理、公开方法签名保持不变。

问题报告者已验证其本地补丁；这不是本轮 GPU 实测。既有调查记录：实际 Core 0.2.6 source `0ac955fc`、A-Jar 包 SHA-256 `d518d17db0ef90d6a5485bb0367bb00aab4cbf9b6ade60d53db85a108f4ab8c6`；探针曾观察到三路无 frame 情况仍注入，五类反编译均无 `isSDLGPU`，并且 0.2.4→0.2.6 对应源码无变化。证据位于 `E:/CodeGT/.artifacts/core-issue27-investigation/probe.json` 与 `probe-run.log`。

同一组45项新后端合同在固定旧0.2.6包上有11项失败，修复后45/45通过。禁用配置缓存后的 `spotlessApply build` 完整构建退出0（38秒），包含既有相机、宽线及Angelica合同。首次针对任务虽实际通过，但其Gradle进程因配置缓存问题失败，不记作该进程整体通过。后端选择与Iris状态使用隔离桩，没有启动游戏、GL或服务器，不将其记为GPU实测。最终打包JAR、Tag、Maven及草稿附件结果见全局工作流后续回执。
