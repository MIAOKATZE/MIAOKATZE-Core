## 真实客户端集成

Core v0.1.12 候选已在真实 4 GiB GTNH 客户端集成通过，并在实际 NEI 中生效。环境为 GT205、BR 1.4.24、Angelica 2.2.28、GTNHLib 0.11.52 与 5Modernity 材质包；实际 NEI 为 2.8.155，材料隔离 API 为 2.8.145。

与正式旧版共同运行的 55 个场景中，原始 RGBA SHA 全部相同、5/5 model fingerprint 相同，GL error 为 0。该结论只覆盖这 55 个共同场景。

NEI 实际 `retainedInts`（四类机器及织机，按固定顺序）为 4.00 / 5.43 / 3.69 / 5.33 / 0.53 百万 ints。固定 640×640、5 次预热加 20 次采样的 CPU 提交 median 为：

| 场景顺序 | 旧版毫秒 | 候选版毫秒 |
| --- | ---: | ---: |
| 四类机器及织机 | 168.91 / 218.74 / 131.95 / 183.55 / 16.91 | 13.78 / 19.10 / 11.78 / 13.71 / 1.35 |

这些数值是固定画布下的 CPU 提交时间，不是整包 FPS 或游戏帧率结论。

`candidate-r1` 整体 PASS，exit 0，用时 148.75 秒，无强停。baseline r1/r2 fixture 中断，r3 raw 结果仍为 FAIL；55 个共同场景各自有效，不把 raw 整体结果改写为通过。
