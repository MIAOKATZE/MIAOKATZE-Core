## 本轮实现

Core 新增公共 ItemOrderCatalog：按精确 Item 身份、damage 和原有 NBT 保持输入，只对目录条目排序；lazy raw supplier 延迟生成原始条目，缓存可失效，API 返回防御性副本。optional NEI bridge 只在客户端存在 NEI 时接入，按 Minecraft/mod/item 标识排序，并保留显式 name 注册优先级。common 路径不加载 NEI 类。旧 Core API 保留。

五个 Mod 只声明各自物品的领域与等级顺序；本轮依赖、Forge 最低版本及 FPL 坐标同步升级到 Core 0.1.10。
