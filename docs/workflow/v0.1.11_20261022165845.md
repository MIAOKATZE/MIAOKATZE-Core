## API 与兼容合同

新增向后兼容入口 `WorldCameras.tryActivate`，用于显式用户操作中的相机激活。相同 priority 的当前相机允许移交给新的显式激活；较低 priority 不能抢占较高 priority。原有 `WorldCameras.tryAcquire` 接口及行为不变，callback 重入与 stale-lease 行为保持原有合同。`docs/world-camera` 已新增方法说明，其余既有 API 未变。

## 已完成验证

10 项主合同检查通过，包含新增的相等优先级移交、高优先级保护、回调重入与 stale lease 断言。首次 `spotlessApply build` 因仓库既有 `processResources` configuration-cache 脚本捕获问题退出 1，合同检查通过；随后 `build --no-configuration-cache` 用时 4 秒 PASS。`test` 为 `UP-TO-DATE`，没有声称在该次构建中新跑测试。未修改无关 `build.gradle` 配置。
