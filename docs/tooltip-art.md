# 原生 Tooltip 标题动效

`TooltipTable.withArt(TooltipArt.…)` 选择组标题的装饰。默认 `PLAIN` 完全沿用原字体和颜色，不占印记宽度；选择以下任一风格后，标题前留 8×8 GUI 像素的印记和 2 像素间隙。标题只轻微调色；警告、材料、数字和单位不参与变化。即使没有颜色，蒸汽的两缕气纹和裂隙的折口也有不同轮廓。

| 可选风格 | 形状与节奏 |
| --- | --- |
| `ACCENT` | 珍珠灰空心环；微光沿斜向缓慢穿过。 |
| `GRID` / `DATA_STREAM` / `QUANTUM` | 电网用带节点的折线路径，数据流用三排错开的短包，量子化以菱形两半交替显色。 |
| `STEAM` / `RIFT` / `SHARD` | 浅青汽纹向上移动；淡紫裂隙两边错时受光；冷灰碎晶的三个切面依次显光。 |
| `CAT` / `COIN` / `HEARTH` | 杏色猫耳点亮后到面颊；旧金色钱币上斜向掠过一道短光；粉杏色心从中心缓慢暖起。 |
| `BLUEPRINT` | 蓝色图纸的直角尺沿水平线、竖线依次描亮。 |

GTSR 维度锅炉冷却剂、激活剂标题分别选择 `STEAM`、`RIFT`。表中其余风格是 Core 供消费者选用的能力，未替其他 Mod 注册物品或改变其既有主题。

**绘制约定**：本地单调时钟 `TooltipAnimationClock` 给印记及标题取同一相位。每个印记是一张四顶点小矩形，`seal.vert` 使用当前 GUI 投影与模型矩阵，`seal.frag` 按同一 8×8 掩码生成着色，不采集屏幕或改写字体纹理。实际文字继续由当前 Chromatic 字体回调绘制；名称和数字不占用全局 § 控制码。OpenGL 3.0 不可用、SDL GPU 后端或编译/链接失败时，固定管线绘制同一轮廓，保留可读文字。资源重载丢弃自有 program/VAO 并重新尝试。关闭该物品动效时，不执行自有着色器，印记和文字都固定；印记不隐去，版面不变。

**审阅**：同一组样例先对比默认与关闭动效，再对比长名称和窄屏；不把图形当作唯一的工况或报警信号。工坊的位图字体试排、实际 GLSL 的离屏采样与背包/NEI 的真实画面分别标注。只有最后一种能验收整合包的 Tooltip 绘制管线。
