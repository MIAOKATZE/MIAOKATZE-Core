# BoundedMru（0.1.15）

`api.collection.BoundedMru.moveToFront(entries, entry, limit, sameIdentity)` 返回最近访问优先的不可变列表。新记录排在第一位，同身份旧记录及输入中的其他重复身份被折叠，其他记录保留顺序，结果不超过正整数 `limit`。方法不修改输入列表；元素仍为调用方对象引用，身份比较器必须满足等价关系。

该 API 只处理通用顺序与容量。机器注册身份、玩家权限、目标有效性、网络消息、NBT 存档及测试维度由各 Mod 自行负责，记录存在不授予远程访问权限。GTSR 的终端历史是首个消费者。

0.1.15 仅新增类与方法，不更改已有公开 API。使用该方法的消费者应将 Core 编译依赖、Forge 最低版本及精确补下载版本一并更新到 0.1.15；其他 Mod 的依赖下限保持各自实际需要。
