## 实现范围

新增通用 `api.ui.component` 类型：`UiNode`、`UiScene`、`UiRect`、`UiStyle`、`UiRenderer`、`UiEvent`，以及客户端 `MinecraftUiRenderer`。组件引擎保留节点树，按布局变更标记 dirty 状态；裁剪区域与命中测试一致，支持事件捕获/冒泡、焦点与文本输入、滚动和组件生命周期。children 缓存只在结构改变时重建，不逐帧克隆。既有 API 与相机行为不变，不承载终端 UUID 或设备业务语义。

## 首次构建

- 纯 Java 8 独立 contracts 通过；新增 `UiComponentContracts` 已挂入 `check`。
